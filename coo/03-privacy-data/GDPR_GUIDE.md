# 글로벌 개인정보 대응 가이드

## HEALO가 대응해야 하는 법규

| 법규 | 적용 대상 | HEALO 해당 여부 |
|---|---|---|
| 한국 개인정보보호법 | 한국 사업자 | ✅ 필수 |
| GDPR (EU) | EU 거주자 데이터 처리 시 | ✅ EU 환자 가능 |
| CCPA (미국 캘리포니아) | 캘리포니아 거주자 | ⚠️ 미국 환자 포함 시 |
| PIPA (일본) | 일본 거주자 | ⚠️ 일본 시장 진출 시 |

## 핵심 요구사항 비교

| 요구사항 | 한국법 | GDPR | 현재 HEALO 상태 |
|---|---|---|---|
| 수집 전 동의 | ✅ 필수 | ✅ 필수 | ⚠️ 체크박스만 있음 |
| 보관 기간 고지 | ✅ 필수 | ✅ 필수 | ❌ "as long as necessary" |
| 삭제 요청권 | ✅ 보장 | ✅ 보장 | ⚠️ 수동만 가능 |
| 제3자 제공 동의 | ✅ 별도 동의 | ✅ 별도 동의 | ❌ 미구분 |
| 쿠키 동의 | ⚠️ 권고 | ✅ 필수 | ❌ 배너 없음 |
| DPO 지정 | 조건부 | 조건부 | ❌ 해당 시 필요 |
| 유출 신고 | 72시간 | 72시간 | ❌ 매뉴얼 없음 |

## 조치 우선순위

1. 쿠키 동의 배너 구현 (GDPR 즉시 대응)
2. 개인정보처리방침에 보관 기간 구체화
3. 제3자 제공(병원) 별도 동의 추가
4. 삭제 요청 자동화
5. 유출 사고 대응 매뉴얼 작성
