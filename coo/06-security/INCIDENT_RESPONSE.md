# 보안 사고 대응 매뉴얼

## 개인정보 유출 사고 대응 절차

### ⏰ 시간 제한
- **한국 개인정보보호법**: 유출 인지 후 **72시간 이내** 신고
- **GDPR**: 유출 인지 후 **72시간 이내** 감독기관 신고

### 1단계: 탐지 및 초기 대응 (0~1시간)

1. **유출 범위 파악**
   - 어떤 데이터가 유출되었는가? (이름, 이메일, 의료정보 등)
   - 몇 명의 데이터가 영향을 받았는가?
   - 유출 경로는 무엇인가? (해킹, 내부 실수, 시스템 취약점)

2. **즉시 차단**
   - 유출 경로 차단 (API 키 교체, 비밀번호 변경 등)
   - Supabase 서비스 키 즉시 로테이션
   - 영향받은 사용자 세션 무효화

3. **증거 보존**
   - 서버 로그 백업
   - 유출 시점 DB 스냅샷
   - 관련 API 호출 기록 보존

### 2단계: 신고 (1~24시간)

4. **개인정보보호위원회 신고**
   - 신고 포털: privacy.go.kr
   - 전화: 1833-6972
   - 필요 정보: 유출 항목, 시점, 규모, 조치 사항

5. **영향받은 사용자 통지**
   - 이메일로 유출 사실 통지
   - 통지 내용: 유출 항목, 시점, 조치 사항, 피해 최소화 방법

### 3단계: 복구 및 재발 방지 (24~72시간)

6. **시스템 복구**
   - 취약점 패치
   - 암호화 키 로테이션
   - 모든 관리자 계정 비밀번호 변경

7. **재발 방지**
   - 사고 원인 분석 보고서 작성
   - 보안 강화 조치 이행
   - 정기 보안 감사 일정 수립
