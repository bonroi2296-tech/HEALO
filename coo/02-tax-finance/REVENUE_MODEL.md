# HEALO 수익 모델 설계

## 현재 상태

- 결제 시스템: 미구현
- 수수료 구조: 미정
- 매출: $0

## 수익 모델 옵션

### 옵션 A: 성과 기반 수수료 (추천)
- 병원이 HEALO를 통해 환자를 받으면 시술비의 **10~20%** 수수료
- 장점: 초기 병원 영업 쉬움 (리스크 없음)
- 단점: 환자 → 병원 직접 연락 시 수수료 회피 가능

### 옵션 B: 리드 판매
- 문의 건당 **$50~200** (시술 종류별 차등)
- 장점: 예측 가능한 매출
- 단점: 병원 입장에서 전환율 불확실

### 옵션 C: 구독형 리스팅
- 병원 월 **$200~500** 리스팅료
- 우선 노출 + 리드 우선 배정
- 장점: 안정적 반복 매출
- 단점: 초기 병원 확보 어려움

### 옵션 D: 하이브리드 (A + C 조합, 최종 추천)
- 기본 리스팅: 무료
- 프리미엄 리스팅: 월 $300 (우선 노출)
- 성사 수수료: 10% (모든 병원)
- 이유: 진입 장벽 낮추면서 성과 기반 수익 확보

## 구현 로드맵

1. **계약서**: 병원과의 파트너 계약서 템플릿 작성
2. **정산 시스템**: 월별 정산 → 세금계산서 발행
3. **결제 연동**: Stripe (해외) + 토스페이먼츠 (국내) 검토
4. **대시보드**: 병원별 매출/정산 현황 관리
