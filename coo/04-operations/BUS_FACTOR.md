# 1인 운영 리스크 대응 (Bus Factor = 1)

## 현실

대표님이 2주간 업무 불가능 상태가 되면 어떤 일이 벌어지는가?

| 기능 | 대표 부재 시 | 영향 |
|---|---|---|
| 문의 응답 | 중단 | 환자 이탈, 신뢰 상실 |
| 병원 소통 | 중단 | 파트너십 약화 |
| 서버 장애 대응 | 불가 | 서비스 다운 |
| 환불/분쟁 | 불가 | 법적 문제 |
| 결제/정산 | 중단 | 현금흐름 문제 |

## 대응 전략

### 1단계: 문서화 (즉시)
- [x] 개발 환경 설정: `AGENTS.md` 완료
- [ ] 운영 매뉴얼: 일일 체크리스트
- [ ] 비상 연락망: 세무사, 변호사, 파트너 병원 담당자
- [ ] 계정 접근 정보: 안전한 곳에 모든 계정 비밀번호 보관

### 2단계: 자동화 (1~3개월)
- [ ] 문의 자동 응답
- [ ] 에러 자동 알림
- [ ] 정기 백업 자동화
- [ ] 결제/정산 자동화

### 3단계: 위임 체계 (3~6개월)
- [ ] 파트타임 CS 담당자 (프리랜서)
- [ ] 파트타임 DevOps (긴급 대응)
- [ ] 파트너 병원 직접 소통 채널

## 대표님 건강 관리

개인사업자에게 대표의 건강 = 사업의 건강입니다.

### 번아웃 방지 체크리스트
- [ ] 주 1일 이상 완전 오프
- [ ] 업무 시간 한도 설정 (예: 하루 10시간 이내)
- [ ] 운동 루틴 (최소 주 3회)
- [ ] 정기 건강검진 (연 1회 이상)
- [ ] 자동화로 반복 업무 제거

### 비상 시나리오
1. **1~3일 부재**: 자동 응답 시스템이 처리, 긴급 건만 모바일로 확인
2. **1~2주 부재**: 파트타임 CS가 기본 응대, 기술 이슈는 AI 에이전트 활용
3. **1개월+ 부재**: 사전 지정된 대리인이 운영, 법률/세무 대리인 활성화
