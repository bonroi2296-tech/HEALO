이 폴더는 HEALO 프로젝트의 **비기술적 리스크와 기회**를 체계적으로 관리하기 위한 COO 운영 문서입니다.

## 구조

```
coo/
├── README.md                    ← 이 파일
├── RISK_REPORT.md              ← 전체 리스크 & 기회 분석 보고서
├── 01-legal/                   ← 법률/규제 관련
│   ├── CHECKLIST.md           ← 법적 준수 체크리스트
│   └── ACTION_ITEMS.md        ← 즉시 조치 사항
├── 02-tax-finance/            ← 세무/재무 관련
│   ├── CHECKLIST.md           ← 세무 체크리스트
│   └── REVENUE_MODEL.md       ← 수익 모델 설계
├── 03-privacy-data/           ← 개인정보/데이터 관련
│   ├── CHECKLIST.md           ← 개인정보 준수 체크리스트
│   └── GDPR_GUIDE.md         ← 글로벌 개인정보 대응
├── 04-operations/             ← 운영/자동화 관련
│   ├── AUTOMATION_PLAN.md     ← 자동화 로드맵
│   └── BUS_FACTOR.md         ← 1인 리스크 대응
├── 05-growth/                 ← 성장/마케팅 관련
│   ├── GLOBAL_EXPANSION.md    ← 글로벌 확장 전략
│   └── MARKETING_CHECKLIST.md ← 마케팅 체크리스트
└── 06-security/               ← 보안 관련
    └── INCIDENT_RESPONSE.md   ← 보안 사고 대응 매뉴얼
```

## 사용법

1. `RISK_REPORT.md`를 먼저 읽고 전체 그림을 파악
2. 각 영역의 `CHECKLIST.md`로 현재 상태 점검
3. `ACTION_ITEMS.md`의 즉시 조치 사항부터 실행
4. 분기별로 체크리스트 재점검
