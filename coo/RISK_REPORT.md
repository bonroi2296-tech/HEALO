### 1. 외국인환자유치업 미등록 상태에서 운영 중

**현재 상태:** 코드에 "Pending (Will be updated upon official issuance)"로 표시됨
(`src/lib/siteSettings.js`)

**리스크:**
- 의료법 제27조의2에 따라 **외국인환자유치업 등록 없이 유치 행위를 하면 3년 이하 징역 또는 3천만원 이하 벌금**
- 외국인 환자에게 병원을 연결하고, 비교 견적을 제공하는 행위 자체가 "유치"에 해당
- 현재 HEALO가 하는 일: 치료 비교 → 문의 수집 → 병원 연결 = **명백한 유치 행위**

**조치:**
- [ ] 외국인환자유치업 등록 즉시 완료 (관할 보건소)
- [ ] 등록 완료 전까지 **실제 환자 유치 활동 일시 중단** 고려
- [ ] 등록 후 `siteSettings.js`의 등록번호 업데이트

### 3. 쿠키 동의 없이 추적 중 (GDPR/ePrivacy 위반)

- ePrivacy Directive: 필수 쿠키 외 사전 동의 필수

**조치:**
- [ ] 쿠키 동의 배너 구현 (필수/마케팅 쿠키 분리)
- [ ] GA는 동의 후에만 로딩하도록 변경
- [ ] 쿠키 정책 페이지 추가 (현재 없음)

### 8. 환자 커뮤니케이션 부재

**현재 상태:**

**리스크:**

- 카카오/WhatsApp/Line 자동 응답 봇
- 환자 포털: 진행 상황을 실시간으로 확인

**조치:**
- [ ] 문의 접수 자동 확인 이메일 구현
- [ ] 진행 상태 알림 시스템 설계

### 10. 자동화 부재 (수작업 많음)

**현재 상태:**

- 병원 응답 추적: 수동
- 성과 통계 갱신: 수동 스크립트
- 환자 후속 연락: 수동
- 데이터 백업: 자동화 없음

**기회 (AI COO 관점에서 자동화 우선순위):**
1. **문의 → 병원 자동 매칭**: 리드 스코어링 + 병원 성과 기반
2. **병원 견적 자동 요청**: 이메일/카카오 자동 발송
3. **환자 자동 안내**: 견적 도착 알림, 예약 가이드
4. **일일 리포트 자동 발송**: 관리자에게 매일 오전 브리핑
5. **DB 백업 자동화**: Supabase → 외부 스토리지
